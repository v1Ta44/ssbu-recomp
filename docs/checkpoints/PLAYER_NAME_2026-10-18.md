# 游戏内名字修复 — 2026-10-18

- 原因：Console 只有联机入口传入名字，普通启动忽略已保存的名字；运行时随后回退到 Windows 用户名。
- 所有启动模式统一读取开始页的必填名字；清空会持久保存，旧联机页的显式设置按缺键规则兼容。
- Console、PowerShell/Python 启动器、原生运行时均阻止缺失/无效名字；移除操作系统用户名和硬编码游戏名回退。
- 运行时、Console、脚本和打包说明收束在同一修复提交；不修改游戏文件、游戏生成代码或 mod 内容。
- 离线验证：原生账号资料探针及现有网络回环、Console 配置迁移及所有模式启动门禁、诊断脚本、浏览器交互和布局。
- mod 开启/关闭宿主均完成链接；实机启动与游戏内显示由用户验证。
