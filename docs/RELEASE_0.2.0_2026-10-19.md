# 0.2.0 原生 mod 兼容更新（2026-10-19）

发行版本为 0.2.0，更新序号为 4，沿用个人 fork 的 yuzu-test 测试通道。序号独立于显示版本，因此从 2026.10.19.2 / 2026.10.19.3 升级不受版本字符串格式变化影响。

## 修复范围

只修改 tools/mod_backend 的兼容层，不改第三方 mod 的 config.json、模型、贴图或音频。

- new-dir-files 在完成新增资源及共享别名解析后处理；跳过不存在的目录或文件并给出含配置来源的警告，行为与原生加载习惯一致。
- 共享来源保留原始 FileInfoIndex 和压缩字节，通过内部虚拟别名供原生共享组枚举。公开路径继续对应 mod 替换内容，避免对局前一直等待已改变身份的共享资源。
- 保留现有 yuzu 运行时及其渲染、后台运行、联机和延迟滑块功能。本次没有改变着色器加载策略。启动时缓存预热不等于重新完整编译，不需要清理缓存。

## 发行与复核流程

使用 scripts/release_update.py 生成同版本的签名增量更新、完整文件更新及纯净便携程序包，另附源码和 SHA256。所有公开附件不含 data.arc、第三方 mod、存档、配置、缓存或私钥；便携包仅含空白昵称的默认启动模板。

增量基础包括已公开的 2026.10.19.2、原始 2026.10.19.3，以及本地已经安装并验证兼容修复的独立签名基线。后者使用独立 build_id，避免将修改后的 DLL 冒充原始 .3 基础，也不放宽更新器对未知文件修改的拒绝规则。

安装测试在隔离目录使用实际更新器完成，核对全部发行文件哈希、精确回滚以及玩家文件保留。公开上传先传附件、核对远端大小及 SHA256，最后替换已签名 update.json。旧附件保留，避免破坏已取得旧清单的客户端。发布与本地安装的实际结果另记于 work/release-0.2.0/。
